# Trip - Bookings

:::note[TL;DR]
Attach bookings (flights, hotels, cars, activities, ...) to a day, with a reference, notes, and attachments, to keep confirmations next to your itinerary.
:::

Within a day, you can add bookings to keep track of reservations tied to that day: flights, hotels, cars, trains, boats, activities, or anything generic. Each booking can hold a label, a reference number, notes, and PDF attachments (tickets, confirmations, ...).

<div style={{textAlign: 'center'}}><sup>Trip - Bookings in the day section</sup></div>

:::tip
When creating a booking, you can link it to multiple days at once, useful for a hotel stay spanning several nights.
:::
